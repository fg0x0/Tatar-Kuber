> ## ⚠️ Superseded by [v1.0.1](https://github.com/ochmunkh/Tatar-Kuber/releases/tag/v1.0.1) — do not use this version for live scans
>
> An audit found that **live scans with v1.0.0 under-report**: all findings came from Kubescape alone.
> Trivy and Popeye were detected as installed and their versions were recorded in the report, but they
> contributed **nothing** — Trivy's rule IDs never matched the registry (`AVD-KSV-0017` vs `AVD-KSV0017`),
> `trivy k8s` defaults to `--report summary`, and adapter errors were silently swallowed. Popeye
> additionally mapped 7 of its 10 rules to the **wrong** canonical control.
>
> For a security posture tool this is the worst failure mode: it produces a false sense of safety.
> **If you ran an assessment with this version, re-run it with v1.0.1.**
> v1.0.1 records every scanner's outcome in `metadata.scanner_runs` (shown as a *Scanner coverage*
> table in the report), so an empty or failed scanner can no longer pass unnoticed.
>
